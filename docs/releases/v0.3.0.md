# Command Table v0.3.0

## Install or update with Docker

Use `ghcr.io/addison16/commandtable:latest` with the published Compose file. Existing installations should make a verified backup, keep their Compose project, configuration, data volume and public origin, then pull and recreate the service:

```sh
docker compose -p mtg-util -f compose.yaml pull
docker compose -p mtg-util -f compose.yaml up -d
docker compose -p mtg-util -f compose.yaml ps
```

The compatibility image at `ghcr.io/addison16/commanders-table:latest` receives the same release. Pin `0.3.0` or an image digest when a fixed version is preferred. Do not use `down -v` during an update. See the [Docker hosting guide](https://github.com/Addison16/commanders-table/blob/v0.3.0/docs/deployment.md) for installation, HTTPS, backups and restoration. Browser clients can use **Save & update** when prompted.

## What changed

- **Light, dark, or your device's setting:** Appearance now offers a warm ivory light theme, the existing ink-and-gold dark theme, and automatic device matching. Choose it from Home settings or **Game menu → Display & preferences**. The preference belongs to this browser and does not change other players' displays.
- **A complete interface theme:** setup, player counters, sheets, trackers, card readers, notices and dice overlays follow the selected appearance. Player colors, dice materials and commander artwork retain their identity, with readable overlays on illustrated panels.
- **Remembered appearance from the first frame:** the saved choice is applied before the interface loads and persists through reloads, cached offline use and prompted application updates. Device mode responds to system changes while the app is open, including offline. Older profiles receive a compatible default without losing saved games.
- **More room for dense phone tables:** narrow landscape layouts with five to eight players use two columns and taller panels so life totals, touch controls and player details remain clear.
- **A quieter phone background:** the page glow ends 25% higher in phone portrait and landscape, retaining the desktop presentation and both themes' colors.

This release does not change gameplay rules, shared-room permissions, database identifiers or the SQLite schema. Existing local saves, guest memberships and exports remain compatible. Installation is optional; cached offline use requires a successful initial load in a supported HTTPS or localhost context.
